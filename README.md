# AI-Powered Enterprise Trading & Inventory Management Platform

A production grade Enterprise Trading & Inventory Management Platform built with Django, Django REST Framework, PostgreSQL, and React. The goal is to build a scalable backend that manages business operations while integrating AI-powered features for smarter decision making.

---

## Goals

- Build a production-ready backend
- Learn enterprise software architecture
- Develop scalable REST APIs
- Integrate AI into business workflows

---

## Tech Stack

### Backend
- Django
- Django REST Framework
- PostgreSQL


### Frontend
- React

## Getting Started

```bash
git clone https://github.com/Harshit130127/AI-Powered_Enterprise_Trading_and_Inventory_Management_Platform

cd trading

python -m venv venv

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
